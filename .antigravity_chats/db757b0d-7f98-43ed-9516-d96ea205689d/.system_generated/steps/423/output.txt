There is no single "official" build database API provided by Riot Games. The **Riot Games API** primarily provides raw game data, such as match history, player profiles, and ranked ladder standings, rather than pre-calculated champion builds[1][2].

To access build data (like popular items, runes, and skill orders), you generally have two options:

### 1. Build Your Own Data Pipeline (Using Riot API)
Many developers create their own build databases by fetching high-level match data from the official Riot API and calculating the statistics themselves[3][4].
*   **How it works:** You use the Riot API to pull match data for high-ELO players, store that data in your own database (e.g., PostgreSQL, MongoDB, or SQLite), and run algorithms to aggregate win rates, item pick rates, and rune popularity[3][5].
*   **Official Source:** You can register for an API key and access documentation at the [Riot Developer Portal](https://developer.riotgames.com/)[6][7].

### 2. Use Third-Party APIs
If you do not want to calculate build statistics from scratch, several third-party services offer APIs that provide aggregated champion meta data[8][9].
*   **[dpm.lol API](https://dpm.lol/):** Provides access to champion tier lists, per-lane builds, and rune/item statistics[8][9]. It is designed for developers and offers SDKs for easier integration[9].
*   **[LeagueBuilds](https://github.com/CookieDecide/LeagueBuilds):** An open-source project that includes a backend API which calculates and serves recommendation data based on master+ player match data[3].

### Key Considerations for Developers
*   **Rate Limits:** The official Riot API has strict rate limits[5][2]. You will need to manage these carefully or use a caching layer/database to store data for repeated requests[5][4].
*   **Policy Compliance:** If you are building a public application, you must follow the [Riot Games Developer Policy](https://developer.riotgames.com/policies/general)[10][11]. This includes registering your product on the developer portal, adding mandatory legal disclaimers, and ensuring you provide a free tier for users[10][11].
*   **Data Dragon:** For static data (item icons, champion names, descriptions), use **Data Dragon**, which is a static data resource provided by Riot that does not require an API key and is much easier to implement for basic reference info[12].
