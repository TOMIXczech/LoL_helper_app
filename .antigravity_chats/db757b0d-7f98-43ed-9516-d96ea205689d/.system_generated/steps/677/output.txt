Custom League of Legends item sets are JSON files that you can place in your game's configuration folder to have them appear in the in-game shop[1][2].

### File Structure & Format
To create a valid item set, your JSON file must follow a specific structure[1][2]. Below is the required format[1][2]:

```json
{
  "title": "Your Set Name",
  "type": "custom",
  "map": "any",
  "mode": "any",
  "priority": false,
  "sortrank": 0,
  "blocks": [
    {
      "type": "Block Name",
      "items": [
        { "id": "1055", "count": 1 },
        { "id": "1082", "count": 1 }
      ]
    }
  ]
}
```

### Where to Place the Files
Once you have your JSON file, place it in the corresponding directory based on whether you want it to be global or champion-specific[1][2]:

*   **Global Item Sets:**
    `League of Legends\Config\Global\Recommended\`[1][2]
*   **Champion-Specific Item Sets:**
    `League of Legends\Config\Champions\{championKey}\Recommended\`[1][2]
    *(Note: You can find champion keys using Riot's Data Dragon API[1][2].)*

### Tools and Resources
*   **LoL-ItemsJSON:** A GitHub project that provides a userscript to help export item builds from sites like Mobafire into the correct JSON format for the game client[3][4].
*   **CommunityDragon:** For raw game data, including item IDs and assets, [raw.communitydragon.org](https://raw.communitydragon.org) is a primary resource used by developers[5][6].
*   **In-Game Import:** Remember that the modern League of Legends client also allows you to copy JSON text to your clipboard and **Import Item Sets** directly via the **Collection > Items** tab, which is often easier than manual file placement[3].
