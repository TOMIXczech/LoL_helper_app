The search for "league of legends public builds api json github" returned the following summary:
There is no official "public builds" API from Riot Games. The **Riot Games API**[1][2] and **Data Dragon**[3] provide game data (such as champion stats, match history, and item information), but they do not provide pre-calculated "best builds" or community-driven build recommendations[4].

To obtain build data in JSON format, developers typically use one of the following approaches:

### 1. Community-Maintained Projects (GitHub)
Several open-source projects scrape or aggregate build data to provide it in a usable format:
*   **[LeagueBuilds](https://github.com/CookieDecide/LeagueBuilds):** A project that automates the generation of champion builds by analyzing high-level (Master+) match data[5]. It provides a REST API that you can interact with[5][6].
*   **[LoL-ItemsJSON](https://github.com/EagleExe/LoL-ItemsJSON):** A browser script that extracts item data from community guide sites (like Mobafire) and converts them into the JSON format required for the League of Legends client’s "Import Item Sets" feature[7].
*   **[CommunityDragon (CDragon)](https://github.com/CommunityDragon):** While more focused on raw game assets and champion/item data (including ability scaling), it is a primary source for developers who need accurate, up-to-date static data that is often cleaner than Riot's official Data Dragon[8][9].

### 2. Building Your Own Data Pipeline
If you require specific, statistical build data, most developers build their own pipeline using the official Riot API[10][11]:
*   **Step 1:** Use the **Riot API** (`match-v5` endpoint) to fetch match history for high-rank players[5][12].
*   **Step 2:** Parse the JSON response to extract item purchase orders, rune selections, and skill orders[12][13].
*   **Step 3:** Aggregate this data in your own database (e.g., SQLite or MongoDB) to calculate win rates and pick rates for specific items[5][14].

### 3. Alternative Third-Party Options
*   **[Apify LoL Scraper](https://apify.com/parseforge/ddragon-lol-scraper):** Tools like this can be used to scrape champion and item data programmatically if you do not want to maintain your own backend[15].
*   **Embeddable Widgets:** Some platforms, like [Mobalytics](https://mobalytics.gg/), offer widgets that can be embedded into your own website to display builds without you needing to manage the underlying data[16].

### Important Considerations
*   **API Keys:** If you use the official Riot API, you must register for a developer account on the [Riot Developer Portal](https://developer.riotgames.com/)[10][17]. Development keys have strict rate limits (e.g., 20 requests per second)[4].
*   **Compliance:** Ensure your project follows Riot's "Developer API Policy"[18][19], which includes requirements for legal disclaimers and limitations on commercialization[18].
