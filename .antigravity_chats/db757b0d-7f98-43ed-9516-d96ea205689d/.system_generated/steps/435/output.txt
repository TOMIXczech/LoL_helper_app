There is no single official or standard "builds.json" file for League of Legends on GitHub[1][2]. Because League of Legends data is complex and changes frequently with patches, many developers create their own JSON structures for specific tools, scripts, or personal use[3][2][4][5].

If you are looking for League of Legends build-related data or tools on GitHub, you are likely encountering one of the following types of projects:

*   **Item Set Exporters:** Tools that scrape build websites (like Mobafire or ProBuilds) and convert them into JSON files that can be imported directly into the League of Legends client as custom item sets[3][2].
*   **Data Parsers & Static Data:** Repositories (like `meraki-analytics/lolstaticdata` or `Community Dragon`) that provide accurate, machine-readable JSON files containing champion, item, and ability data, which developers use to build their own apps[6][5].
*   **Build Optimization/Analysis Tools:** Projects that analyze match data to generate optimal build paths[7][4]. These often use custom `builds.json` or similar formats to store the processed results[1][7][4].

### How to find what you need:
*   **If you want to import builds into your game:** Look for "LoL Item Set" generators or exporters on GitHub[3]. These will typically provide a script or a web tool to generate the JSON files for you[3][2].
*   **If you are a developer:** Use established projects like **Community Dragon** or **Meraki Analytics' `lolstaticdata`** for reliable, up-to-date game data[5]. 
*   **If you found a specific "builds.json" in a repo:** Check the repository's `README.md` file[4]. It will usually explain how that specific JSON file is structured and how it is intended to be used within that project[6][4].
