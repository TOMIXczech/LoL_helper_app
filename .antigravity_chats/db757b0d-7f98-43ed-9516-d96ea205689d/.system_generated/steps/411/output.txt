The `lol-perks` endpoints, including those related to `recommended-pages`, are part of the **League Client API (LCU API)**[1][2].

### Important Context
*   **Not a Public Riot API:** These endpoints are part of the internal League Client API, which facilitates communication between the League of Legends client's frontend (Chromium Embedded Framework) and its backend services[2][3]. 
*   **Unsupported for Third Parties:** Riot Games does not officially support or guarantee the stability, documentation, or availability of these endpoints for third-party applications[3]. They are intended for use by the game client itself[2][3].

### Identified Endpoints
Based on LCU API documentation, the following endpoints are associated with recommended perk/rune pages[1][4]:

*   `GET /lol-perks/v1/recommended-pages/champion/{championId}/position/{position}/map/{mapId}`
    *   Retrieves recommended rune pages for a specific champion, position, and map[1].
*   `GET /lol-perks/v1/rune-recommender-auto-select`
    *   Used to fetch auto-selected rune recommendations[1].
*   `POST /lol-perks/v1/rune-recommender-auto-select`
    *   Used to trigger or set the auto-selection of runes[1].
*   `GET /lol-perks/v1/recommended-pages-position/champion/{championId}`
    *   Retrieves position-based recommended pages for a champion[4].
*   `POST /lol-perks/v1/recommended-pages-position/champion/{championId}/position/{position}`
    *   Used to interact with recommended page positions[4].

### How to Access
If you are developing a local tool that runs alongside the League client, you can typically interact with these endpoints by communicating with the local LCU WebSocket/HTTP server. 
*   **Authentication:** You must use the `lockfile` generated by the League client to obtain the necessary authentication credentials (port and base64-encoded password) to make requests to the local `127.0.0.1` address[3].
*   **Security:** Note that the League client uses a self-signed SSL certificate, so your application will need to handle or ignore SSL certificate validation errors when making these HTTPS requests[3].

For official, supported data access, you should use the **Riot Games API** (available via the [Riot Developer Portal](https://developer.riotgames.com/)), though it generally does not provide access to the same client-side "recommended pages" functionality[5][6].
